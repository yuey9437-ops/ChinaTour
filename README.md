# 中国旅游百科全籍

作者：wkawa（yuey9437-ops）

中国 34 个省级行政区、113 个目的地的旅游指南，包含景点、参考路线、美食和住宿资料。

- 在线浏览：https://yuey9437-ops.github.io/ChinaTour/
- 本地预览：在仓库目录运行 \`python -m http.server 8000 --bind 127.0.0.1\`，然后打开 http://127.0.0.1:8000/ 。
- 内容维护：\`data.js\` 保存目的地、行程、坐标来源和照片署名。目的地数组的顺序用于保留已有访问链接。
- 照片：网页中的本地缩略图来自维基共享资源。照片旁列出了原图、作者和许可。没有确定出处及许可的旧图保留在 Git 历史中。
- 坐标：维基资料和 OpenStreetMap 的坐标与高德坐标分开显示。缺少可靠坐标的景点保留地图搜索入口。行程为规划建议，实际出发前请复查交通、开放和预约。
